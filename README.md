# Machine Learning Projects

This repository contains multiple end-to-end Machine Learning projects implemented using Python and Jupyter Notebook.
The projects focus on core supervised learning techniques such as classification, regression, and basic natural language processing (NLP).

These projects were developed to strengthen practical understanding of machine learning workflows including data preprocessing,
model training, evaluation, and prediction.

---

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

---

## Projects Overview

### 1. Iris Flower Classification
- Problem Type: Multiclass Classification  
- Dataset: Iris dataset  
- Objective: Classify iris flowers into different species based on sepal and petal features  
- Models Used: Logistic Regression / KNN  

---

### 2. Heart Disease Prediction
- Problem Type: Binary Classification  
- Dataset: Heart Disease dataset  
- Objective: Predict whether a patient has heart disease based on medical attributes  
- ML Techniques: Data preprocessing, feature selection, classification model  

---

### 3. House Price Prediction
- Problem Type: Regression  
- Dataset: Housing dataset  
- Objective: Predict house prices based on features such as location, size, and rooms  
- ML Techniques: Linear Regression, data analysis  

---

### 4. Loan Status Prediction
- Problem Type: Binary Classification  
- Dataset: Loan application dataset  
- Objective: Predict loan approval status based on applicant information  
- ML Techniques: Logistic Regression, data cleaning, evaluation  

---

### 5. PIMA Diabetes Prediction
- Problem Type: Binary Classification  
- Dataset: PIMA Indians Diabetes dataset  
- Objective: Predict whether a patient is diabetic based on medical parameters  
- ML Techniques: Feature scaling, classification model  

---

### 6. Spam Email Classification
- Problem Type: Text Classification (NLP)  
- Dataset: Spam email dataset  
- Objective: Classify emails as spam or not spam  
- ML Techniques: Text vectorization, supervised learning  

---

### 7. Rock vs Mine Prediction
- Problem Type: Binary Classification  
- Dataset: Sonar dataset  
- Objective: Classify sonar signals as rock or mine  
- ML Techniques: Supervised learning algorithms  

---

### 8. Bitcoin Price Prediction
- Problem Type: Regression  
- Dataset: Bitcoin price data  
- Objective: Predict Bitcoin prices based on historical data  
- ML Techniques: Data analysis, regression model  

---

## Machine Learning Workflow Followed
1. Data collection and loading
2. Exploratory data analysis (EDA)
3. Data preprocessing and cleaning
4. Model training
5. Model evaluation using appropriate metrics
6. Prediction and result analysis
